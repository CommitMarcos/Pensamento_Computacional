# Pensamento_Computacional
Bom, para solucionar esse problema, foi necessário pensar como o sistema poderia ser iniciado sem ocorrer erros. O primeiro processo para essa atividade foi posicionar os elementos - denominados como 
Arduíno, Potenciomêtro, Resistor, Placa de ensaio e Led RGB - na área de trabalho. Após isso, iniciou-se a fase de montagem da questão da seguinte maneira: 

No Led RGB, que possui quatro pontas, sendo três para resistores e uma ponta (catódica) para entrada negativa; 

O terminal 1 foi para entrada "~9", o terminal 2 foi para entrada "~10" e, por fim, o terminal 3 foi para entrada "~11";

Foi posto na Placa de Ensaio os três Potenciomêtros pedidos na atividade de maneira correta, sendo suas pontas esquerda e direita, que ficam nas extremidades, foram colocas para o lado negativo e positivo,
respectivamente, e seus meios nas entradas "A0, A1 e A2" nessa mesma ordem.

Na placa também foram colocados fios na entrada GND e 5V, uma para entrada negativa enquanto a outra para positiva.

Depois de ter realizado a montagem do aparelho "físico" na mesa de trabalho no TinkerCad, a segunda parte da missão foi realizar, na parte de Blocos, o código que, de maneira exata, ligasse  o Led RGB e mudar
